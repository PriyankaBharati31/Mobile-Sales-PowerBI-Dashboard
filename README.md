# Mobile Sales Power BI Dashboard

## Project Overview

This project is a Power BI dashboard created to analyze mobile sales data, customer behavior, brand performance, and city-wise sales trends.

The dashboard helps in understanding:

* Sales performance
* Customer preferences
* Brand-wise analysis
* Product performance
* City-wise sales trends
* Payment method analysis

---

## Tools Used

* Power BI
* Excel
* DAX

---

## Dataset Information

The dataset contains:

* Mobile brands
* Mobile models
* Sales transactions
* Customer ratings
* Payment methods
* City details
* Units sold
* Product prices

---

## Dashboard Features

### 1. Dashboard Overview

* Total Sales
* Total Units Sold
* Average Rating
* Sales Trends

### 2. Customer Analysis

* Payment Method Analysis
* Brand Ratings
* Average Sales Per Transaction

### 3. Product Analysis

* Top Performing Mobile Models
* Brand-wise Sales
* Monthly Brand Performance

### 4. City Analysis

* City-wise Sales
* Units Sold by City
* Average Sales Per Transaction by City

---

## Key Insights

* Delhi and Mumbai generated the highest sales.
* Apple and Samsung were the top-performing brands.
* Customers preferred UPI and Credit Card payments.
* Some cities showed higher spending per transaction, indicating demand for premium smartphones.

---

## Conclusion
This dashboard provides useful business insights that help understand customer behavior, sales trends, and product performance using interactive Power BI visualizations.
